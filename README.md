# 学習暗記カード PWA版

GitHub Pages にそのまま置けます。

## 主なファイル
- index.html: ホーム
- subjects.json: 科目一覧
- manifest.webmanifest: PWA設定
- service-worker.js: オフライン/キャッシュ
- social/index.html
- kanji/index.html
- english/index.html

## 科目を増やす
1. 新しいフォルダ（例 math）を作る
2. その中に index.html を置く
3. subjects.json に1件追加する

新しい科目ページは一度開くと自動キャッシュされます。

## ホーム画面に追加
- iPhone: Safari → 共有 → ホーム画面に追加
- Android: Chrome → メニュー → ホーム画面に追加 / アプリをインストール

## 英語を読む力・28日チャレンジ
- ホームの「英語を読む力・28日チャレンジ」から利用できます。
- 15語の初回診断、28日分のフォニックス／単語／短文／読解、音声確認と自己判定、苦手復習、達成率・正答率グラフ、手動学習時間記録を追加。
- 発音自動採点は行いません。音声合成は端末のWeb Speech APIに依存します。
- 記録はlocalStorageの reading28_progress_v1 に保存し、チャレンジ画面からJSONバックアップ・復元可能。「データ引き継ぎ」でも含まれます。
- 他の既存アプリのファイルと保存キーは変更していません。
